# make ai: лендінг послуги

Односторінковий лендінг для єдиної послуги **make ai**: система контенту для Instagram. Мова сторінки: українська.

## Що в послузі
Одна послуга без розбиття на пакети. Вона об'єднує:
1. Стратегію й рубрикатор.
2. Контент щомісяця: каруселі та Reels, 1 лід-магніт.
3. Дизайн-систему у Figma (шаблони для охопного, навчального, продажного контенту й лід-магнітів, хедери, фони, палітра, шрифти, інструкція). Файл передається клієнту.
4. Воронку: кодове слово → бот або Telegram → заявка.
5. Самонавчання воронки: результати (теми, формати, офери, точки випадіння) фіксуються в базі, і наступний цикл підлаштовується під них.
6. Аналітику й місячний звіт. Таргет підключається за потреби, рекламний бюджет клієнта окремо.

Орієнтовна вартість на сторінці: від $600/міс (взято з початкової таблиці, потребує підтвердження).

## Структура
- `landing/index.html`: вся сторінка в одному файлі (HTML, CSS, трохи JS), без збірки.
- `docs/session-notes.md`: історія рішень із сесії розробки.

## Візуальний стиль
За референсом Prisma (motionsites.ai): темна кінематографічна тема, кремова палітра, hero в заокругленій рамці з великим логотипом, плашки-«чіпи» для навігації та пунктів розділу «Детально». Шрифти Manrope і Cormorant (курсив) із Google Fonts, обидва підтримують кирилицю.

## Запуск
Відкрийте `landing/index.html` у браузері. Фонове відео hero підтягується з зовнішнього URL, без нього показується анімований градієнт.

## Що замінити перед публікацією
- Посилання `https://t.me/your_username` і підпис `@your_username` на справжній Telegram.
- Ціну й терміни (три тижні до запуску), якщо вони інші.
- Цифри в прикладі звіту умовні, їх варто замінити реальними кейсами.
