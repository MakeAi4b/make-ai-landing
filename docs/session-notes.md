# Історія рішень

1. **Вихідні дані.** Таблиця з трьома продуктами: «Дизайн-кіт» (разово), «Старт» (≈ $500/міс), «Ріст» (≈ $600+/міс, бюджет реклами окремо). Завдання: упакувати все в одну послугу й зробити лендінг.
2. **Додано до послуги.** Дизайн-система у Figma для різних типів контенту, що передається клієнту, і воронка, яка вчиться на результатах (фіксує дотики з клієнтом і послугою, вносить у базу, підлаштовується).
3. **Перша версія** російською, з демо-слайдами, палітрами й хедерами. Відхилена.
4. **Друга версія** українською, три кроки з цінами. Відхилена: послуга одна, її треба розписати детально.
5. **Назва проєкту:** make ai.
6. **Третя версія** у стилі Prisma (промпт із motionsites.ai): темна тема, кремова палітра, hero-рамка, картки, розділ «Детально» з вісьмома блоками.
7. **Четверта версія:** навігація першого екрана й пункти розділу «Детально» оформлені плашками, як на референсі-скріншоті.

## Відкриті питання
- Остаточна ціна єдиної послуги.
- Справжній Telegram для кнопок.
- Реальні кейси замість умовного прикладу звіту.
- Чи потрібне відео в hero: у публікації як артефакт зовнішні відео блокуються.
